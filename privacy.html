02

استضافة الموقع — GitHub Pages

يتم نشر الموقع باستخدام GitHub Pages. عند زيارة موقع مستضاف عبر GitHub Pages، يوضح GitHub أن عنوان IP الخاص بالزائر يتم تسجيله وتخزينه لأغراض أمنية، حتى لو لم يكن الزائر مسجلاً الدخول إلى GitHub.

هذه المعالجة تتم ضمن البنية التحتية لخدمة الاستضافة، ويخضع التعامل مع هذه البيانات لسياسات GitHub الخاصة بالخصوصية والأمان.

03

إحصاءات الزيارات — GoatCounter

يستخدم Infograf+ خدمة GoatCounter لمعرفة عدد الزيارات للموقع بصورة إحصائية. لا نستخدم Google Analytics أو Meta Pixel أو أدوات إعلانية لتتبع المستخدمين.

وفقاً لوثائق GoatCounter، يتم تخزين بيانات إحصائية مجمعة مثل الصفحة، المتصفح، النظام، اللغة، عرض الشاشة، والموقع على مستوى تقريبي مستنتج من عنوان IP. ولا يتم تخزين عنوان IP نفسه أو قيمة User-Agent الكاملة في قاعدة البيانات، كما لا يستخدم GoatCounter ملفات تعريف ارتباط أو localStorage أو معرّف تتبع دائم لهذا الغرض.

يتم استخدام بيانات الإحصاءات لفهم استخدام الموقع وتحسين المحتوى والبنية العامة، وليس لإنشاء ملفات شخصية إعلانية.

04

الوضع الداكن والتخزين المحلي

يتيح الموقع اختيار الوضع الفاتح أو الداكن. يتم حفظ هذا الاختيار محلياً في متصفحك باستخدام localStorage تحت مفتاح خاص بالموقع.

هذه المعلومة لا تُرسل إلى خادم الموقع ولا تُستخدم للتتبع أو الإعلانات، وإنما لحفظ تفضيل العرض لديك.

05

الخطوط والموارد المحلية

يستخدم الموقع خط Cairo المستضاف محلياً على نفس الموقع. لذلك لا يتم إرسال طلب إلى Google Fonts لتحميل الخط عند زيارة الموقع.

06

الروابط الخارجية

يحتوي الموقع على روابط خارجية، منها Instagram وFacebook. هذه الروابط ليست محتوى مضمّناً داخل الموقع. عند الضغط عليها والانتقال إلى الخدمة الخارجية، تصبح معالجة البيانات خاضعة لسياسة الخصوصية الخاصة بتلك الخدمة.

لا يتم تحميل محتوى Instagram أو Facebook داخل صفحات Infograf+ بشكل تلقائي.

07

البحث في الموقع

وظيفة البحث في Infograf+ تعتمد على بيانات الإنفوغرافيكات الموجودة ضمن الموقع. لا يتم إرسال كلمات البحث إلى خدمة إعلانات أو محرك بحث خارجي من خلال وظيفة البحث نفسها.

08

أما أي تواصل مباشر عبر البريد الإلكتروني، فتتم معالجة البيانات اللازمة للرد على الرسالة وعلى أساس الغرض من التواصل والمصالح المشروعة، أو على أساس قانوني آخر إذا كان ذلك مطلوباً بحسب طبيعة الطلب.

03

Besucherstatistik — GoatCounter

Infograf+ verwendet GoatCounter, um die Anzahl der Websitebesuche statistisch auszuwerten. Wir verwenden kein Google Analytics, kein Meta Pixel und keine werbebezogenen Tracking-Dienste.

Nach Angaben von GoatCounter werden aggregierte statistische Informationen wie Seite, Browser, System, Sprache, Bildschirmbreite und ein aus der IP-Adresse abgeleiteter ungefährer Standort verarbeitet. Die IP-Adresse selbst und der vollständige User-Agent werden nicht in der Datenbank gespeichert. GoatCounter verwendet für diese Statistik keine Cookies, kein localStorage und keine dauerhaft gespeicherte Tracking-ID.

Die Statistik dient ausschließlich dazu, die Nutzung der Website zu verstehen und Inhalte sowie Aufbau der Website zu verbessern. Es werden keine Werbeprofile erstellt.
